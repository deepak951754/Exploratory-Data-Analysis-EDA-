# EDA Explorer — Exploratory Data Analysis Project

An interactive Exploratory Data Analysis (EDA) dashboard built using HTML, CSS, and JavaScript.

This project helps users explore datasets, identify patterns, analyze data quality, visualize trends, and generate useful insights.

## Features

- Interactive data analysis dashboard
- Upload your own CSV dataset
- Dataset structure and data type analysis
- Missing value detection
- Duplicate value and duplicate row detection
- Potential outlier detection
- Revenue trend visualization
- Category-wise revenue chart
- Data distribution histogram
- Discount vs. sales scatter plot
- Automatic data insights
- Searchable data preview
- Download sample CSV dataset
- Responsive design for desktop and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- SVG Charts

## Installation and Usage

1. Download the EDA Explorer HTML project.
2. Rename `eda_explorer_project.html` to `index.html`.
3. Open the file in Google Chrome, Microsoft Edge, or another modern browser.
4. Click **Upload CSV dataset**.
5. Select your CSV file to explore your data.

No Python installation or additional libraries are required.

## Deployment

This project can be deployed using Netlify.

1. Create a folder named `eda-explorer`.
2. Place the HTML file inside the folder.
3. Rename the file to `index.html`.
4. Visit https://app.netlify.com/
5. Sign in and use the manual deployment option.
6. Upload your project folder using the available deployment interface.
7. Copy the public website URL generated by Netlify.

## EDA Workflow

1. Ask meaningful questions about the dataset.
2. Inspect variables, data types, and dataset structure.
3. Identify trends, patterns, and unusual values.
4. Analyze missing data and potential duplicates.
5. Explore relationships using charts.
6. Summarize findings and validate assumptions.

## Dataset

The project includes a sample retail sales dataset for demonstration.

Users can upload their own CSV files to explore different datasets.

## Limitations

- This is an educational EDA tool.
- Data types are inferred automatically and may need verification.
- Outlier detection uses a simple IQR-based method.
- Automatically generated insights are descriptive, not proof of causation.
- The dashboard does not replace advanced statistical analysis.
