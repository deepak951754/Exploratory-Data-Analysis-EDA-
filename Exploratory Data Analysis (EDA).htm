    2. Which category contributes the largest share of sales?

    About this EDA project

    EDA Explorer is a browser-based project that demonstrates a typical exploratory data analysis workflow. It summarizes a dataset, infers basic column types, visualizes distributions and relationships, and flags potential quality issues.

    Built with: HTML, CSS, JavaScript and SVG charts. No Python packages or server are required.

    Input: CSV files with a header row. Column names like Sales/Revenue, Date/Month, Category/Product, and Discount are used when available; other numeric and text columns are still profiled.

    Limitations: This is a lightweight educational EDA tool, not a replacement for full statistical analysis in Python/R. Outliers use an IQR heuristic; data types are inferred from sample values.
